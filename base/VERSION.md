# Versión Base de IdA

- **Origen:** IdA v14 (foto de rescate de arquitectura v12/v13)
- **Fecha de corte:** Noviembre 2026
- **Propósito:** Organismo bioinspirado de referencia para el laboratorio. Sirve como punto de partida para bifurcar variantes en `variantes/` y contrastar contra líneas base tradicionales en `lineas-base/`.

## Contenido de la Base

- `nivel_1_core/`: Núcleo inmutable, interocepción, contratos vitales, Tribunal motor y gestión de onda. Ciego a dominios específicos.
- `nivel_2_sistemas/`: Sistemas cognitivos S1 (reactivo), S2 (límbico), S3 (racional), plasticidad TD-hebbiana, ciclo de sueño y bucle talamocortical.
- `nivel_3_componentes/`: Adaptadores de mundo (`mundos/`: archivos/bosque, snake, crafter, ajedrez) y órganos universales.
